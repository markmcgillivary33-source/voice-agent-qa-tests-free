# Free Voice Agent QA Tests

Ten representative scenarios from Voice Agent QA Lab's Home Services Starter Edition.

- `sample.jsonl` — one JSON object per line.
- `sample.csv` — spreadsheet-friendly export.
- `index.html` — offline viewer for this free sample.
- `schema.json` — JSON Schema for validating the scenario records.

## Free online tools

- Production site: https://voice-agent-qa-lab.vercel.app
- Browser scorecard: https://voice-agent-qa-lab.vercel.app/scorecard
- Build-generated QA reports: https://voice-agent-qa-lab.vercel.app/reports
- Machine-readable agent manifest: https://voice-agent-qa-lab.vercel.app/agent-manifest.json
- Crawler and LLM overview: https://voice-agent-qa-lab.vercel.app/llms.txt

The complete 100-case pack covers HVAC, plumbing, electrical, and roofing workflows, including tool failures, hallucinations, unauthorized actions, and safety escalations. The full pack is available as a one-time download at the production site.
